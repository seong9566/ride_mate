# ADR-0007 — 에이전트 하네스 구조

- 상태: **채택** (2026-11-09)

## 결정

- Claude Code와 Codex가 같은 지침을 읽는다. 정본은 `backend/AGENTS.md`이고 `backend/CLAUDE.md`는 `@AGENTS.md` 한 줄이다.
- 하네스는 `backend/` 안에만 둔다. 레포 루트에는 `CLAUDE.md`를 두지 않고, 세션은 `backend/`에서 시작한다.
- 레이어 규칙의 정본은 `backend/docs/`다. 스킬에는 그 작업 고유의 규칙(하지 말 것, 만들 파일, 절차, 완료 조건)만 쓴다.
- 코드 템플릿은 스킬 폴더의 `templates/`에만 둔다. 문서에는 규칙과 템플릿 경로만 쓴다.
- 스킬 정본은 `backend/.agents/skills/`이고 `backend/.claude/skills/`는 정본을 가리키는 심볼릭 링크다.
- git 훅은 `.git/hooks/`에 심볼릭 링크로 설치하고 `core.hooksPath`는 바꾸지 않는다.

## 근거

- 모노레포라 모빌리티 앱 작업에 백엔드 지침이 섞이지 않아야 한다.
- 같은 규칙이나 템플릿을 두 곳에 적으면 어긋난다. 실제로 Repository의 DTO 규칙이 두 문서에서 서로 달랐던 적이 있다.
- 스킬 구조(SKILL.md는 짧게, 템플릿은 옆 파일)는 Claude 공식 스킬 작성 지침을 따랐다.
- 전역 `core.hooksPath`가 `.git/hooks/`의 훅으로 위임하는 구조라, 로컬에서 `core.hooksPath`를 바꾸면 전역 훅이 꺼진다.

## 결과

- 레포 루트에서 시작한 Codex는 `backend/.agents/skills/`의 스킬을 찾지 못한다.
- 스킬을 추가하면 `.claude/skills/`에 링크를 하나 더 만들어야 한다.
