# ADR-0020 — 주차장 데이터는 공영만, 출처가 다르면 최신 기준일 우선, 빈자리는 공단 실시간

- 상태: **채택** (2026-11-12)
- 기능 명세서 06 시트(공공데이터 연동) 1·2번의 출처를 실제로 쓸 수 있는 것으로 바꾼다. 명세서 정정은 기획 쪽에 넘긴다.

## 결정

- 대기 장소 추천(RM-V05)은 **공영 주차장만** 다룬다. 민영 주차장은 요금·운영 시간을 믿고 받을 출처가 생길 때까지 넣지 않는다.
- 시설·요금·운영 시간·좌표는 n8n 워크플로 `parkingCollect01`이 하루 1회 두 출처에서 받아 `PARKING_LOT`에 적재한다.
  - 전국주차장정보표준데이터(data.go.kr 15012896): 대치동·평촌 모두
  - 서울시 공영주차장 안내 정보 `GetParkInfo`(서울 열린데이터 OA-13122): 대치동
- 두 출처가 같은 주차장에 다른 값을 주면 **기준일이 더 최신인 쪽**을 쓴다. 표준데이터는 `referenceDate`, 서울시는 `LAST_DATA_SYNC_TM`의 날짜를 비교하고, 같으면 서울시 값을 쓴다. 고른 출처와 기준일은 `FEE_SOURCE`·`FEE_BASE_DATE`에 남긴다.
- 실시간 빈자리는 한국교통안전공단 주차정보 `PrkRealtimeInfo_v1`(data.go.kr 15099883)에서 받는다. 수집기가 공단 시설 좌표가 적재 주차장에서 100m 안이면 `REALTIME_REF`로 연결하고, API 서버가 추천 때 시군구 단위로 조회해 `AVAILABLE_SPACES`에 5분 캐시한다.
- 서울시 시영주차장 실시간(OA-21709)은 쓰지 않는다.

## 근거 (2026-11-11~12 실측)

- 공단 시설 정보의 민영 주차장은 요금·운영 시간이 전부 비어 있다(대치 1km 안 1,687곳 중 0곳). 표준데이터에는 대치·평촌 1km 안 민영 주차장이 0곳이다. 서울주차정보는 공개 API가 없고, 민영 정보는 사업자 자율 신고라 실제와 다를 수 있다고 스스로 안내한다. 아이파킹·모두의주차장은 제휴 없이 쓸 공개 API가 없다.
- 공단 운영 정보는 추가 요금이 0으로 비어 있어(예: "30분 1,800원 + 추가 10분 0원") 금액이 틀린다. 표준데이터와 서울시 `GetParkInfo`는 대치 공영 요금이 서로 같고, 시안 금액(도곡초교·대치2문화센터 5분 300원, 도곡로421 5분 400원)과도 맞는다.
- 서울시 `GetParkInfo`는 좌표가 전부 0이라 좌표는 표준데이터 값을 쓴다. 두 출처의 연결은 이름 정규화와 동 이름으로 한다. 2026-11-12 기준 대치동 23곳 중 15곳이 연결됐다.
- 같은 주차장이 공단에 ID 두 개로 등록돼 있다. 공영 레코드에는 실시간이 없고, 따로 등록된 레코드에만 실시간이 있다. 그 별도 레코드의 관리주체는 '민영'으로 잘못 적혀 있다. 그래서 관리주체가 아니라 좌표로 연결한다. 도곡초교의 실시간 레코드는 표준데이터 좌표에서 약 53m 떨어져 있어 연결 거리를 100m로 잡았다.
- 공단 실시간은 `prk_center_id` 조건을 무시하고 전국 목록을 돌려준다. 그래서 시군구(`sidoCd`·`sigunguCd`) 단위로 받는다. 강남구는 28곳이 실시간을 내고, 안양 동안구는 0곳이다.
- 시영 실시간(OA-21709)은 시영 122곳만 다루고 구 운영 공영주차장(도곡초교 등)은 없다.

## 받아들인 위험

- 평촌 공영 주차장은 대부분 추가 요금이 비어 있다. 이런 곳은 금액을 계산하지 않고 기본 요금 문구("30분 200원")만 보여 준다.
- 서울시 `LAST_DATA_SYNC_TM`은 동기화 시각이라 값이 실제로 바뀐 날이 아닐 수 있다. 그래서 서울 공영은 대개 서울시 값이 이긴다.
- 표준데이터 기준일은 한두 달 늦다(평촌 2026-09-15, 대치 2026-10-22). 요금 개정이 늦게 반영될 수 있다.
- 실시간 조회가 실패하면 오래된 저장값을 그대로 쓴다(`docs/architecture/schema.md`).

## 결과

- 민영 주차장을 넣을 때는 새 ADR을 쓴다. 제휴나 새 출처를 확보한 뒤에 넣는다.
- 공공데이터포털 키 `DATA_GO_KR_API_KEY`가 n8n(`$env.DATA_GO_KR_API_KEY`)과 API 서버(`PublicData:ServiceKey`) 양쪽에 필요하다. 키는 원문이든 URL 인코딩된 값이든 같은 값으로 정규화해 쓴다.
- 표준데이터를 받을 때는 전국 약 19,000건을 페이지마다 미리 걸러야 한다. 모두 들고 가면 `n8n execute`가 메모리 부족으로 종료됐다.
