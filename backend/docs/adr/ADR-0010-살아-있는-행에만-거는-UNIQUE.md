# ADR-0010 — 살아 있는 행에만 거는 UNIQUE

- 상태: **채택** (2026-11-10)

## 결정

삭제 표시된 행과 겹칠 수 있는 조합의 중복은 생성 컬럼 `ACTIVE_FLAG`(`DELETE_YN = 0`이면 1, 아니면 NULL)를 UNIQUE 키 끝에 넣어 막는다.

## 근거

- 물리 삭제를 하지 않으므로 그냥 UNIQUE를 걸면 삭제한 뒤 같은 값을 다시 넣을 수 없다.
- UNIQUE 없이 Service에서만 중복을 확인하면 동시에 들어온 두 요청이 둘 다 통과한다.
- UNIQUE는 NULL끼리 겹치는 것을 허용하므로 삭제된 행은 걸리지 않는다.

## 결과

- 이 방식을 쓰는 테이블마다 컬럼이 하나 는다.
- 중복 키 오류를 Service에서 "이미 있음"으로 바꿔야 한다.
- 스캐폴드는 생성 컬럼을 일반 컬럼으로 잡는다. `RideMateContext.Extensions.cs`에서 이름이 `ActiveFlag`인 속성을 저장 대상에서 뺀다.
