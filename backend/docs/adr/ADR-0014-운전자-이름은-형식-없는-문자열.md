# ADR-0014 — 운전자 이름은 형식 없는 문자열

- 상태: **채택** (2026-11-11)
- ADR-0012의 "운전자 실명, 화면에는 성만 남기고 가린다"를 대체한다. 계정 테이블 이름과 QR 코드 분리는 ADR-0012 그대로다.

## 결정

- `USER_INFO.USER_NAME`은 실명이 아니라 운전자가 입력한 이름 문자열이다. 타입(`VARCHAR(50)`)과 필수(NOT NULL)는 그대로 둔다.
- 이름 형식(한글만, 숫자·특수문자 금지 등)은 검사하지 않는다. 빈 값과 50자 초과만 거절한다.
- 차량의 계정 목록(RM-V00)에는 입력한 그대로 보여준다. 「김OO」처럼 가리지 않는다.

## 근거

- 사용자 결정(2026-11-11): 운전자 이름은 그냥 문자열로 받는다.
- 이름은 한 차량에 로그인한 계정을 구분하는 표시용 값이다. 실명인지 확인할 수단이 없고, 확인할 필요도 없다.

## 결과

- 입력한 값이 실명일 수 있으므로 개인정보 수집 항목으로 다루는 것은 ADR-0012와 같다. 계정을 삭제할 때 `USER_NAME`을 빈 문자열로 비운다.
- DB 컬럼 설명을 "운전자 실명"에서 "운전자 이름"으로 바꿨다(`sql/20261111_user_name_comment.sql`).
