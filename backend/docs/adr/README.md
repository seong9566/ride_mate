# ADR — 결정 기록

백엔드의 구조·스택·작업 방식에 영향을 주는 결정을 남긴다. 규칙 자체는 `backend/AGENTS.md`와 `backend/docs/`에 있고, 여기에는 그 규칙을 **왜** 정했는지를 적는다.

- 새 결정은 `ADR-NNNN-제목.md`로 쓴다. 번호는 이어서 붙이고 재사용하지 않는다.
- 상태는 `제안`·`채택`·`폐기`·`대체됨` 중 하나다. 결정을 뒤집으면 새 ADR을 쓰고 옛 ADR을 `대체됨(→ ADR-NNNN)`으로 바꾼다. 일부만 뒤집으면 옛 ADR을 `채택(일부 대체 → ADR-NNNN)`으로 둔다.
- 규칙 문서에서는 `[ADR-NNNN]`으로 인용한다.
- 아직 정하지 않은 것(배포처)은 ADR로 쓰지 않는다. 정할 때 쓴다.
