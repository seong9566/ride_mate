# ADR-0008 — 개인정보 저장 위치와 픽업 세션 익명화

- 상태: **채택** (2026-11-10)

## 결정

- 부모는 서버가 발급한 익명 키(`PARENT.PARENT_KEY`)로 구분한다. 로그인은 두지 않는다.
- 아이 이름·전화번호·시간표는 서버 DB에 저장한다. 전화번호는 암호화한다.
- 픽업 세션은 끝나면 물리 삭제하지 않는다. `DELETE_YN`을 켜고 부모·아이·시간표·학원 참조를 NULL로 바꾼다. 학원가·픽업 지점·시각만 남은 행을 익명 기록으로 쓴다. 익명 기록 테이블은 따로 두지 않는다.
- 부모와 아이를 삭제할 때도 `DELETE_YN`을 켜면서 이름·전화번호·위치 값을 비운다. 오래 쓰지 않은 부모는 서버가 같은 방식으로 삭제한다.
- 감사 컬럼 `CREATE_USER`·`UPDATE_USER`에는 역할(`PARENT`·`CHILD`·`SYSTEM`·`ADMIN`)만 넣는다.
- 링크 토큰은 서버 비밀키와 행의 난수로 계산하고, 해시만 저장한다. 링크가 끝난 뒤에도 해시는 남긴다.
- 픽업 지점·시각 배정은 학원가(`AREA`) 행을 잠가 한 학원가씩 순서대로 처리한다. 정원은 차 수로 세고, 형제는 같은 지점·칸을 쓴다.
- 삭제된 행과 겹칠 수 있는 조합의 중복은 생성 컬럼 `ACTIVE_FLAG`를 넣은 UNIQUE로 막는다.
- 제외 구역·경로처럼 선과 면이 필요한 값은 MySQL 공간 타입으로 저장한다.

## 근거

- 서버가 도착 시각을 배정하려면 시간표를 알아야 한다. 차량에만 두면 차를 바꾸거나 앱을 다시 설치할 때 사라진다.
- 기획의 "픽업 후 세션 삭제, 서버에는 구역·시각 등 익명 정보만"은 픽업이 끝난 뒤의 기록에 적용한다.
- 차량 SDK에는 사용자 계정 API가 없다. 차대번호 조회는 있지만 앱 마켓과 사전 협의된 권한만 쓸 수 있어 식별 수단으로 전제할 수 없다.
- 물리 삭제 예외를 만들지 않아 `database.md`의 삭제 규칙이 모든 테이블에 그대로 적용된다.
- 감사 컬럼에 부모 키를 넣으면 참조를 비워도 세션이 누구 것인지 남는다.
- 끝난 세션에 학원 참조를 남기면 익명이 깨진다. 직접 입력한 학원은 등록한 부모로 이어지고, 작은 학원은 날짜와 하원 시각만으로 아이가 좁혀진다.
- 세션만 익명화하고 삭제한 아이의 이름·전화번호를 남기면 균형이 맞지 않는다. 앱을 다시 설치하면 옛 부모 행은 지울 사람이 없다.
- 끝난 링크를 다시 열면 "이 링크는 끝났어요"를 보여줘야 하므로 토큰 해시로 행을 찾을 수 있어야 한다. 해시로는 링크를 다시 만들 수 없다.
- 다시 알릴 때 아이가 이미 연 화면이 끊기지 않으려면 같은 링크를 보내야 한다. 원문을 저장하지 않고 그렇게 하려면 다시 계산할 수 있어야 한다.
- 일반 조회로 세고 넣으면 동시에 들어온 두 요청이 서로의 삽입을 보지 못해 정원을 넘는다. 칸별 카운터 테이블은 취소·재배정·종료마다 값을 줄여야 해서 어긋나기 쉽다.
- UNIQUE 없이 Service에서만 중복을 막으면 동시에 들어온 요청이 둘 다 통과한다.
- 어린이보호구역은 면, 황색선은 선이라 중심 좌표와 반경으로는 담을 수 없다.

## 결과

- 통계 조회와 끝난 링크 조회는 `DELETE_YN = FALSE` 조건을 붙이지 않는다. `database.md`의 조회 규칙에서 이 둘만 예외다.
- 학원별 통계는 낼 수 없다. 학원가·픽업 지점 단위로만 낸다.
- 삭제한 부모·아이는 복구할 수 없다.
- 링크 비밀키가 새면 진행 중인 링크를 위조할 수 있다. 키는 환경변수로만 둔다.
- 한 학원가의 배정은 동시에 처리되지 않는다. 하루 100건 미만이라 문제가 되지 않는다.
- 배정과 상태 바꾸기의 잠금 조회는 Dapper로 쓴다. 쓰기 트랜잭션 안에서 Dapper를 쓰는 방법은 구현할 때 정한다.
- 끝난 세션 행이 계속 쌓인다. 하루 100건 미만이라 당장은 정리하지 않는다.
- 익명화는 세션이 끝나는 트랜잭션 안에서 한다. 빠뜨리면 개인정보가 남으므로 세션을 끝내는 경로를 Service 한 곳으로 모은다.
- EF Core 공급자가 공간 타입 스캐폴드를 지원하지 않으면 공간 컬럼은 Dapper로만 다룬다.
