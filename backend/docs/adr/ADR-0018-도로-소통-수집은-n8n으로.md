# ADR-0018 — 도로 소통 수집은 n8n으로

- 상태: **채택** (2026-11-11)

## 결정

- 대치동의 서울 TOPIS 소통 이력과 평촌의 경기도 GITS 소통 이력은 .NET 서버가 아니라 n8n 워크플로로 수집한다.
- n8n은 같은 compose의 MySQL에 직접 쓴다.

## 근거

- API 서버가 꺼져 있어도 정해진 시간에 수집이 돌아야 한다.
- 스케줄, HTTP, XML, MySQL 처리가 n8n의 기본 노드라 별도 코드가 거의 필요하지 않다.
- n8n 화면에서 실행 이력을 확인할 수 있다.
- 수집기는 데이터를 쓰기만 하며 Controller → Service → Repository 계층 밖에 있다.

## 결과

- 배포처가 정해지면 n8n도 그 배포처로 옮긴다.
- `n8n/workflows/`의 JSON을 정본으로 삼는다. 화면에서 워크플로를 고치면 다시 내보내 커밋한다.
- TOPIS와 GITS 모두 키가 URL에 들어가므로 성공한 실행과 수동 실행의 데이터 저장을 끄고 실행 이력 저장을 줄인다.
