# ADR-0006 — 테스트 프로젝트 없이 빌드와 호출로 검증

- 상태: **채택** (2026-11-09)

## 결정

테스트 프로젝트를 두지 않는다. 대신 아래로 검증한다.

- 경고를 오류로 보는 빌드. `RideMateService.csproj`의 `TreatWarningsAsErrors`와 pre-commit 훅이 강제한다.
- 서버를 띄워 Swagger에서 바꾼 API를 호출해 응답을 확인한다. 로컬 서버와 로컬 Docker DB가 대상일 때만 POST·PATCH·DELETE를 승인 없이 쓴다.
- 라우트·DTO를 바꾸면 `docs/api/openapi.json`을 같은 PR에서 갱신한다.

## 근거

공모전 MVP이고 백엔드 개발자가 1명이라 테스트 프로젝트를 따로 유지하지 않기로 했다. 전역 규칙은 검증 호출을 GET으로 제한하지만, 로컬 환경에서는 쓰기 API를 호출해 보지 않으면 확인할 방법이 없다.

## 결과

- 감사 컬럼 누락, `DELETE_YN` 조건 누락, 응답 문구 오타처럼 컴파일되는 실수는 자동으로 잡히지 않는다.
- 훅 자체는 테스트가 있다(`backend/githooks/tests/test-pre-commit.sh`).
- PR에서 빌드를 돌리는 CI는 아직 없다.
