# 공공데이터 연동

> 생성 파일 — 손으로 고치지 않는다. 정본: `docs/spec/feature-spec.xlsx`

공공데이터 연동 목록 — 차량은 공공데이터를 직접 부르지 않고, 서버가 모아 대치동 기준으로 가공한 뒤 차량에 캐시 (기획서 원칙 · 하드웨어 접근/성능 정책)

구분: 필수(MVP 화면에 바로 쓰임) · 권장(정확도 향상) · 확인 필요(데이터셋 미확정) · 확장(평촌). 데이터 번호·갱신 주기는 2026.11.10 확인 기준이며 개발 전 포털에서 한 번 더 확인
