# WAY:ME 시연 데이터 (2026-11-15)

시연 영상에서 쓰는 값만 모았습니다. 좌표는 대치동 근사값이며 실제 서비스 데이터가 아닙니다.

## 1. 등록할 값 (초기 설정에서 직접 입력)
| 항목 | 값 |
|---|---|
| 아이 이름 / 휴대폰 / 생년월일 | 자유(예: 지민 / 010-0000-0000 / 2014-05-14) |
| 학원 이름 | 수학학원 |
| 학원 장소 / 주소 | ○○수학학원 대치점 / 서울 강남구 대치동 |
| 학원 위치 | 37.49500, 127.06120 → `adb emu geo fix 127.0612 37.4950` 후 "지금 차 위치를 학원 위치로 등록" |
| 요일 | 촬영하는 날의 요일 |
| 하원 시각 | **촬영 시작 + 50분**(5분 단위, 14:00~23:30) → 시작 시 "출발까지 약 19분" → 대기 장소 추천 분기 |
| 집 위치 | 37.48850, 127.05010 → `adb emu geo fix 127.0501 37.4885` 후 "지금 차 위치를 집으로 등록" |

## 4. 화면에 나오는 계산·예시 값
| 값 | 내용 |
|---|---|
| 추천 출발 | 하원 − 31분 |
| 배정 도착 시각 | 하원 + 4분 |
| 집 도착 예정 | 하원 + 25분 |
| 차량 소요 | 현재→학원 근처 32분, 학원 근처→집 18분, 대기 장소→픽업 장소 5분 |
| 픽업 후보 | 1 △△빌딩 앞(추천·도보 5분) / 2 ○○ 앞(지난번·3분) / 3 □□공원 입구(6분) |
| 대기 장소 | 1 도곡초교 공영주차장(5분·약 2,100원·120대) / 2 대치2문화센터 공영(5분·30대) / 3 도곡로421 공영(4분·약 2,800원·10대) |
| 문자 본문 | "{하원+4분}에 차가 도착해요! △△빌딩 앞 주변에서 만나" (실제 발송 없음) |
| 전달 상태 | 보냄 = 누른 시각, 열람 = +1분, 지금 나가요 = 정차 20초 전 |
| 정차 허용 시간 | 60초 (30초 이하 경고, 0초 초과) |

## 5. 실행 순서 요약
1. 에뮬레이터 실행(Cold Boot) → `adb devices`로 확인
2. Virtual Console: `adb forward tcp:8088 tcp:8088` → 브라우저 http://127.0.0.1:8088/
3. GPS 확인: `python3 gps_demo.py check`
4. 가입·초기 설정(위 1번 값) → 앱 종료
5. `adb emu geo fix 127.04905 37.50455`(출발지) → 앱 실행(알림 카드) → 보기 → 픽업 장소 1번 → 대기 장소 1번 "경로 시작"
6. `python3 gps_demo.py play route_cache.json --leg to_waiting --speedup 2` → "지금 출발"
7. `python3 gps_demo.py play route_cache.json --leg to_pickup` → "보내기" → 정차 타이머
8. Virtual Console > Convenience > Door Position: 2열 문 열림 → 닫힘
9. `python3 gps_demo.py play route_cache.json --leg to_home --speedup 2` → 기록 "저장"
